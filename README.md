# A股智能选股工具

一款面向A股投资者的智能选股工具，每日根据技术面、资金面、消息面等多维度数据自动筛选潜在优质股票。

## 功能特性

- **今日精选** - 查看根据策略筛选的股票列表
- **选股策略** - 自定义筛选条件（RSI、MACD、量比、资金流向等）
- **股票详情** - K线图、资金流向、技术指标分析
- **我的收藏** - 收藏并追踪关注的股票
- **历史记录** - 查看历史选股结果

## 技术栈

- React 18 + TypeScript
- Vite
- Tailwind CSS
- ECharts
- Zustand

## 本地开发

```bash
npm install
npm run dev
```

## 构建部署

```bash
npm run build
npm run deploy
```

## 风险提示

本工具所展示的选股结果仅供参考，不构成任何投资建议。股票投资有风险，入市需谨慎。
